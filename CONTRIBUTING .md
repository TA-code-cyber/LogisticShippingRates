Contribution guildlines
Welcome contributors!
Thank you for considering contributing to the cemtralized repositort. This document outline the guildline for contributing to the development of Shipping Rate and Calculators.

Code style
Please follow the code styles and conventionused in the existing codebase. This helps maintain consistency across the project.

Documentation
Ensure your contributions are well - documented. Include comments in your code where necessary and provide a clear and concise description of your changesvin the pull request.

Testing
Before submitting a pull request, make sure you changes have been tested thoroughly. Including relevant test cases and ensure existing test pass.

Issue tracker
Check the issue tracker for any open issue or features requests. If you are working on something, please come on the issue and let others know.

Code reviewcodd
All contributors will go through a code review process. Be open to feedback and be willing to make changes if necesssary. Code review help maintain code quality and consistency.

Thanks for the contribution!
